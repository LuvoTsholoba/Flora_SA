# Flora_SA
FloraSA: An ASP.NET CORE MVC web application that identifies plants and flowers from a picture. Users upload an image or take a picture ,choose a South Africa language and receive a plant name ,description, origin and care instruction generated by Google's Gemine AI

#Features

-Upload an image or take a photo directly from a phone or laptop camera
-Al plant identificatio using Google's Gemini API
-Language selector so results can be returned in South African Languages
-Image Validationn
Friendly error messages when upload or AI request fails
-Responsive results page that shows subumitted image next to the results

#Tech Stack
=BackEnd: C#, ASP.NET CORE MVC, AI ,GOOGLE GEMINI VIA THE Msccc.GenerativeAi.Google
-Front-End :HTML , CSS AND BOOTSTRAP
-Tools : Visual Studio, It ,GitHub

#Limitations
-Web app depends on the AI model and it can be wrong ,so results need to be double checked
-Free gemini tier has usage limits,SO REQUESTS MAY BE REJECTED WEN TE QUOTA IS REACHED

-Build and run the application
